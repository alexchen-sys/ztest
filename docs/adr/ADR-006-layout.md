# ADR-006: repository layout — source modules and one embedded shim

Status: Accepted (v2, 2026-10-26). Replaces the v1 monolithic-source decision.

## Context

The release must remain one self-contained native executable with zero Python
module-search overhead for the runner itself. A source checkout or an installed
Python package cannot be required at runtime. At the same time, a 10,000-line
shim and a 5,000-line platform supervisor are unnecessarily hard to review.

## Decision

### Shim source modules, deterministic bundle

The authoritative shim sources are the numbered files under
`src/shim/modules/`. They are contiguous logical sections sharing one Python
namespace; they are **not** runtime-imported Python modules. This preserves the
old symbol-resolution semantics and avoids an import graph at runtime.

`scripts/bundle_shim.py` concatenates them in a fixed `MODULE_ORDER` into
`src/shim/ztest_shim.py`. The generated file is committed for review and direct
behavioral tests. `--check` fails on any drift, and `build.zig` invokes that
check before compiling the native executable, which embeds only the resulting
bundle with `@embedFile`.

### Private, importable helpers

`_project_detect.py` is deliberately different: it is a small stdlib-only
helper imported lazily by the zygote. It is not concatenated into the bundle.
The native supervisor embeds and writes it beside the extracted bundle in its
private per-run temporary directory. Import resolution therefore uses embedded
bytes, never the caller's checkout, a wheel data directory, or an ambient
source tree. Both files follow the existing private run-directory cleanup.

### Native modules

`src/pal/` owns kernel and libc platform mechanics. `src/main.zig` retains the
rolling dispatcher whose run-scoped state and ADR-004 phases interlock.
Configuration and CLI remain in `src/pyfiles.zig` and `src/cli.zig`.

## Consequences

There is one shipped executable, no runtime compiler, and no source checkout
needed. Module edits require regeneration, enforced both locally by the build
and independently in CI. Adding another importable helper requires explicit
embedding and extraction plus a behavioral test; adding a source section only
requires a manifest entry in `MODULE_ORDER`.

Python tracebacks continue to name the deployed `ztest_shim.py`; behavioral
anti-drift tests compile the exact generated bytes used by the executable.
